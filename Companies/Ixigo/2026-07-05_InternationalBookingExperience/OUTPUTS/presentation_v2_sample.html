MMT's Approach — don't copy
  • Visa via Atlys investment — static 3rd-party integration, not ML
  • Forex via TripMoney — bolt-on card, not predictive re-ranking
  • Each pain point addressed separately, no unified adaptive system
Ixigo's Leapfrog — build this
  • Visa friction → ranking input, not a separate portal
  • Forex decline risk → re-ranks payment methods by predicted risk
  • Trust deficit → guidance surfaces at exact moment of hesitation
Global proof: Airbnb and Booking.com's value sits in invisible ranking layers, not chat UIs. Booking.com runs ~150 ML models underneath a chat surface. No Indian OTA has built this yet.

Recommendation

Build a personalization layer that knows a traveler is "international-curious" before they type a query

Today — blank canvas
  • Every user treated identically until they search
  • Price-ranked results for all queries, including international
  • Visa/forex friction discovered mid-booking or post-purchase
  • Help content surfaces reactively, not at moment of hesitation
International conversion drops at discovery
→
AI-Native — predictive layer
  • Behavioral signals flag "international-curious" users pre-query
  • Destinations re-ranked by visa-friction-adjusted feasibility score
  • Forex decline risk re-ranks payment methods before checkout
  • Policy alerts (e.g. Thailand visa change) surface inline, proactively
1.3–3× GMV multiplier on international bookings

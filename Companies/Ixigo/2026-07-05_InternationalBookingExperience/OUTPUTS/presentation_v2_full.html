v2 separates decision-making (Phase 1: Planning) from decision-implementation (Phase 2: Rendering)

Phase 1: Planning
Understanding → Planning → Storytelling → Slide Planning → Visual Planning. Produces enriched draft.json with narrative arcs, modes, and per-slide blueprints.
Phase 2: Rendering
Brand lookup → Rendering → QA. Reads draft.json + references/rendering.md only. Unchanged from v1 except mode-aware rec-tag and two new patterns.
Payoff
Backward compatible. Planners can pre-decide everything without touching rendering logic. Formatters inherit richer data without rewriting their code.

Planning layer adds six capabilities — narrative arcs, presentation modes, and per-slide blueprints — without touching rendering

  • Storytelling Engine: 7 narrative arcs (problem-to-decision, hypothesis-first, MECE exploration) mapped onto the 12 existing slide types
  • Presentation Modes: 10 modes (interview_assignment, product_strategy, consulting, executive/product/leadership review, technical, research, board, investor) — each tunes visual density, appendix depth, recommendation tag text, communication style
  • Slide Planning: per-slide blueprint schema — explicit slide_type, visual_type, visual_pattern assignments before rendering
  • Visual Planning: routing table that maps each slide's data to a pattern (stat ring, cluster, chain, matrix, bar, before/after, table, funnel)

v1 Approach
  • Brief arrives → Renderer starts immediately
  • Renderer makes on-the-fly decisions: which pattern fits this data? how should this layout stack?
  • No planning artifact; decisions embedded in rendering code
  • Hard to preview structure before building
v2 Approach
  • Brief arrives → Planning produces draft.json with all decisions pre-made
  • Renderer reads decisions off draft.json and implements them
  • Planning artifact (draft.json) is human-readable and auditable
  • Full deck structure visible before rendering starts
Not a rewrite. The renderer itself is unchanged. Only the *input* to the renderer is richer. v1 draft.json still works.

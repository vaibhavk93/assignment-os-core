# PM Frameworks

**JTBD:** "When [situation], I want to [motivation], so I can [outcome]." Use to reframe stated requests as real needs.

**AARRR (Pirate Metrics):** Acquisition (CAC, traffic) → Activation (first value, activation rate) → Retention (D1/D7/D30, churn) → Revenue (ARPU, LTV) → Referral (NPS, K-factor). Use for growth diagnosis.

**North Star Metric:** One metric capturing value delivery — represents user value, correlates with revenue, near-real-time, actionable. E.g. Airbnb = nights booked.

**RICE:** `(Reach × Impact × Confidence) / Effort`. Impact: 3=massive…0.25=minimal. Confidence: 100/80/50%.

**MECE:** Categories don't overlap (mutually exclusive) and together cover everything (collectively exhaustive). Test every breakdown against both.

**Porter's Five Forces:** New entrants, supplier power, buyer power, substitutes, rivalry. Use for market/competitive analysis.

**5 Whys:** Root cause over symptom.

**OKRs:** Qualitative objective + 3-5 measurable, time-bound, outcome-focused key results.

**Kano Model:** Basic (absence dissatisfies) / Performance (linear) / Excitement (delights unexpectedly) / Indifferent / Reverse.

**Pyramid Principle (Minto):** Answer first → 3-ish key arguments → evidence per argument. Governs every deck/memo structure — see `deck-builder` skill for the applied version.

**Hypothesis-driven thinking:** "We believe [X] will cause [users] to [behavior change], resulting in [metric change]. We'll know we're right when [outcome]."

**TAM/SAM/SOM:** Total addressable → serviceable addressable → serviceable obtainable. Top-down (industry report → segment) or bottom-up (unit × price × frequency).

**Outcome vs Output:** Frame recommendations around outcomes ("+15% D7 retention"), never outputs ("build a notification system").

**2×2 Prioritization:** Impact vs effort. Quick wins → do first. Big bets → plan carefully. Fill-ins → if bandwidth. Avoid quadrant → don't.

**A/B Test Framework:** Hypothesis, primary + guardrail metric, treatment/control, sample size, duration, success threshold, rollout plan.
